===============================================================
MINI POS EXPRESS v1.0.0 — PORTABLE CASHIER CLIENT
===============================================================

Aplikasi kasir web modern siap pakai untuk pengujian multi-perangkat
dan verifikasi lisensi terintegrasi Central SaaS LMD.

CARA MENGGUNAKAN DI PERANGKAT LAIN:
1. Hubungkan HP / Laptop Anda ke Wi-Fi yang sama dengan PC Server.
2. Buka browser di perangkat Anda (Chrome / Safari / Edge).
3. Akses alamat:
   http://192.168.0.116:8080/mini-pos/
4. Ikuti panduan wizard aktivasi lisensi otomatis.
